## Deploy in 5 steps

```bash
# 1. Clone or unzip this folder, then:
cd women-leaders-dh

# 2. Install dependencies
npm install

# 3. Test locally
npm start
# Opens at http://localhost:3000

# 4. Deploy to GitHub Pages
# First: create a repo called 'women-leaders-dh' under the transform-health GitHub account
# Then:
npm run deploy
# This builds the app and pushes to the gh-pages branch automatically

# 5. Enable GitHub Pages
# Go to: github.com/transform-health/women-leaders-dh → Settings → Pages
# Set source to: Deploy from branch → gh-pages → / (root)
# Your site will be live at: https://transform-health.github.io/women-leaders-dh
```
